# Mini Blog 📝

Aplicação de blog desenvolvida com **React** e **Firebase**, permitindo que usuários publiquem conteúdos, explorem publicações e gerenciem seus próprios posts por meio de uma interface intuitiva.

## 🚀 Funcionalidades

- **Autenticação de usuários:** cadastro, login e gerenciamento de acesso.
- **Gerenciamento de publicações:** criação, edição e exclusão de posts.
- **Página inicial:** exibição e organização das publicações disponíveis.
- **Visualização de posts:** página individual com os detalhes de cada publicação.
- **Busca de publicações:** pesquisa para facilitar a localização de conteúdos.
- **Controle de permissões:** somente o autor de uma publicação pode editá-la ou excluí-la.

## 🛠️ Tecnologias e conceitos aplicados

- **React:** desenvolvimento da interface por meio de componentes reutilizáveis.
- **React Router DOM:** gerenciamento de rotas e navegação entre páginas.
- **React Hooks:** gerenciamento de estados, efeitos e reutilização de lógica.
- **Context API:** compartilhamento e gerenciamento de estados globais.
- **Firebase:** integração com serviços de backend e persistência de dados.
- **Autenticação:** controle de acesso e identificação dos usuários.
